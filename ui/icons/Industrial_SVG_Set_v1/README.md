# Industrial SVG Set v1 (3DXFlat Advanced)

**Style**
- Monoline, stroke-only, rounded caps/joins
- `stroke="currentColor"` for easy tinting via QSS
- Default viewBox: 24x24 (except `orbit.svg` is 32x32)

**Recommended usage (Qt)**
- Render as QIcon via your existing IconRegistry/IconLoader.
- For hover/checked states: change `color` (QSS) rather than editing SVG.
